Dataset: Australasian Grass-Owl monitoring

Files:
1. Data_Hour_combine.csv
   - Hourly presence/absence data

2. Data_Day_combine.csv
   - Daily presence/absence data

Variables:
- station_id
- date / time
- camera_detection (0/1)
- recorder_detection (0/1)
- breeding_status
- dataset_type (full / effort-standardized)

Notes:
- Effort-standardized data = 1 week/month + 10 min/hour
